# Журнал тренировок (WorkoutLog)

Приложение для учёта тренировок, когда **один человек записывает подходы за всех**.
Сделано на Flutter (Android + iOS + веб).

## Что умеет

- Участники: список пустой на старте, добавляются кнопкой «+». Имена — свои.
- Упражнения: название, дни недели (Пн–Вс). Главный экран сам показывает
  упражнения на выбранный день.
- Быстрый ввод подходов: вес × повторения, кнопки быстрых повторений,
  несколько подходов подряд без закрытия окна.
- Подсказка «неделю назад» — результат того же упражнения ровно 7 дней назад.
- Статистика: по каждому участнику «эта неделя / прошлая / рекорд за всё время»,
  график лучшего веса, история.
- Тоннаж и итог дня (сумма вес × повторы).
- «Повторить прошлый раз» — копирование подходов прошлой тренировки.
- Заметки к тренировке (свободный текст на дату).
- Справочник техники упражнений (подсказка по названию + ручной выбор).
- Светлая / тёмная / системная тема.
- Экспорт и импорт данных (резервная копия) — без интернета.

Все данные хранятся **локально** (один JSON в памяти приложения), интернет не нужен.

## Сборка

### Android

```
flutter build apk --release
```

### iOS (без Mac)

`.ipa` собирается в облаке GitHub Actions (файл `.github/workflows/ios-ipa.yml`,
сборочная машина `macos-14`). Это **неподписанный** `.ipa` — его потом
подписывает SideStore/AltStore под бесплатный Apple ID на самом телефоне.

Запуск: вкладка **Actions** → «Build iOS IPA (unsigned)» → **Run workflow**.
По окончании скачать артефакт `workoutlog-ipa`.
